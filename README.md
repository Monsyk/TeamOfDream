# EcoCafe — версия 6

Статический сайт без фреймворков, сборки и внешних шрифтов. Дата: 21 октября 2026.

В ZIP готовые файлы сайта находятся в корне. Для GitHub Pages опубликуйте `index.html`, `style.css`, все `.js` и папку `assets`, сохраняя относительные пути. В рабочем репозитории эти же файлы находятся в `dist/`.

## Изменения версии 6

- У еды удалены внешняя рамка и пустые полосы вокруг фотографии. На компьютере фото и текст занимают одинаковую высоту, без лишнего вертикального пространства.
- На телефоне горизонтальное фото еды расположено над текстом на той же ширине; тарелка и блюдо сохраняются в кадре.
- Все 22 снимка отредактированы встроенным imagegen по предоставленным оригиналам: напитки центрированы в шаблоне 4:5, еда — 4:3. Крупные английские надписи удалены, сохранены детали напитков/блюд и небольшая фирменная маркировка. Общая подача — светлый дубовый стол, мягкая зелень и естественный свет.
- Новые файлы: `assets/menu/p*-v6-480.webp` и `p*-v6-800.webp`. Исходные WebP сохранены рядом для дальнейшей работы.
- Точные задания на редактирование и образец сохранены в `menu-photo-edit-prompts.json`, соответствия и происхождение — в `menu-photo-manifest.json`. Режим — встроенное редактирование изображений, без CLI/API.
- Цены, состав меню, корзина, примерка, карта и остальные блоки сохранены.

## Изменения предыдущей версии

- Восстановленное приветственное изображение 1536×1024 и облегчённый вариант 800 px. Без зелёных рамок, затемнения и растягивания маленького исходника. Детали реконструированы с ИИ по предоставленному фото; это не новая фотосъёмка.
- Предложение и кнопки видны сразу. Эффект плавной прокрутки сохранён на компьютере, но не блокирует меню. Анимация меняет transform, сглаживается по времени, прекращает работу в покое и за экраном. На мобильной ширине и при уменьшении движения закреплённая сцена отключена.
- Меню содержит только 22 позиции с предоставленными фотографиями. Медовый капучино, эспрессо, листовой чай и классический круассан исключены. Их данные сохранены в `menu-photo-manifest.json` для возможного возврата после получения фотографий.
- Первой открывается классика. Фото в компактных горизонтальных карточках, русские названия и явные цены. Американо 200 мл — 220 ₽, капучино 200 мл — 280 ₽, латте 300 мл — 300 ₽. Неизвестные цены дополнительных объёмов не придуманы.
- Печать — 50 ₽ на один подходящий напиток. Если она уже включена в авторский напиток, повторной доплаты нет. Флажок печати применяется ко всем экземплярам одной позиции.
- Корзина всегда справа в закреплённой шапке и сохраняется в этом браузере через localStorage. Онлайн-заказы и оплата не подключены: корзина — список для визита.
- Примерка своего фото работает локально: изображение не отправляется на сервер, не сохраняется в localStorage и не передаётся принтеру. Для печати нужно показать оригинал бариста. Поддерживаются JPEG, PNG и WebP до 8 МБ и 24 Мп.
- Пример бариста сохранён в примерке; приветственное изображение используется отдельно.
- Полное фото принтера раскрывается по нажатию, три модели стаканов собраны в одном кадре без продажи и цен. Видео и места под него отсутствуют.
- Карта Шахт с филиалом ДГТУ и зелёной зоной радиусом 200 м сохранена. Локация планируемая; точный адрес, открытие и график ещё не объявлены.

## Файлы

- `index.html` — содержание и статические карточки меню.
- `style.css` — оформление и адаптивность.
- `app.js` — каталог, фильтры, корзина и локальная примерка.
- `cart-core.js` — расчёт корзины и печати.
- `cinema.js` — анимация при прокрутке.
- `map.js` — лёгкая карта OpenStreetMap, тайлы запрашиваются при попадании карты на экран.
- `menu-data.json` — справочная копия текущего каталога; при изменении меню синхронизируйте карточки в HTML и массив products в app.js.
- `menu-photo-manifest.json` — соответствия фотографий, исключённые позиции, дубли и происхождение приветственного изображения.
- `AUDIT.md` — подробная критика, принятые исправления и оставшиеся ограничения.
- `checks.json`, `verify.py`, `qa-interactions.cjs` — результаты и проверки. Для запуска нужны Python 3 и Node.js; для самого сайта они не нужны.

Проверки из папки проекта или распакованного ZIP:

    python3 verify.py
    node qa-interactions.cjs

Для локального просмотра можно запустить `python3 -m http.server 8000` из папки готового сайта. Карта требует доступа к OpenStreetMap. Автоматическое копирование корзины требует HTTPS; при недоступности API показывается поле для ручного копирования.

## Проверка и ограничения

Проверены Chrome на компьютере и мобильная компоновка в iframe 390 px, корзина, фото, раскрытие принтера и карта. Автоматические проверки проходят. На физическом слабом компьютере и реальном телефоне проверки не проводились, Core Web Vitals не измерялись. Фотографии меню — визуализации, отредактированные с ИИ по предоставленным снимкам; крупные надписи внутри них удалены. Перед реальным открытием подтвердите цены, рецептуры, материалы стаканов, адрес и время работы.
